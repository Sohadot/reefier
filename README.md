# Reefier

**Structural Intelligence Beneath the Surface.**

Reefier is a naming and reference asset for systems whose intelligence,
resilience, and consequence form beneath what is immediately visible.

It names a structural condition — depth, interconnection, and resilient
internal form that exceed surface legibility — and offers that condition as
a transferable identity for institutional, analytical, and strategic work.

This repository contains the public source for
[reefier.com](https://reefier.com).

## Reference structure

- **Home** — the word, its definition, operational forms, and an illustrative Index application
- **Manifesto** — the argument for structural depth
- **Framework** — the Reefier Index methodology: dimensions, formula, tiers, and limits
- **About** — institutional posture, stewardship, acquisition, and transaction security
